# 3070. Count Submatrices with Top-Left Element and Sum Less Than k

**Difficulty:** Medium
**Topics:**  Matrix,Prefix Sum
**Date Solved:** 2026-03-18
**LeetCode Link:** [Link](https://leetcode.com/problems/count-submatrices-with-top-left-element-and-sum-less-than-k/description/)
## Solution
```java
// Your code here
class Solution {
    public int countSubmatrices(int[][] grid, int k) {
        int cnt=0;
        int n=grid.length;
        int m=grid[0].length;
        int[][] arr=new int[n+1][m+1];
        for(int i=0;i<n;i++){
            for(int j=0;j<m;j++){
                arr[i+1][j+1]=grid[i][j]+arr[i+1][j]+arr[i][j+1]-arr[i][j];
                if(arr[i+1][j+1]<=k){
                    cnt++;
                }
            }
        }
        return cnt;
    }
}
